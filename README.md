# TravelTrip_MVCProject

📌 Bu proje ile ASP.Net MVC5'i pratik yaparak sıfırdan Full Stack Web Geliştirme öğrenme yolculuğumda ikinci projemi yapmış oldum. Projeyi Murat Yücedağ'ın Youtube kanalında bulunan <i>"50 Derste MVC5 ile Tatil & Seyahat Sitesi"</i> eğitim serisini takip ederek Admin Panel için gelişmiş bir tema kullanmadan W3Layout blog temasıyla basit bir kişisel seyahat, gezi blog web sitesi geliştirdim. <a href="https://www.youtube.com/playlist?list=PLKnjBHu2xXNNhJQ6SyF7Wyhqza9mkMGSw" target="_blank"> Buraya</a> tıklayarak eğitim serisine ulaşabilirsiniz.
