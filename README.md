# TravelTrip_MVCProject

📌 Bu proje ile ASP.Net MVC5'i pratik yaparak sıfırdan Full Stack Web Geliştirme öğrenme yolculuğumda ikinci projemi yapmış oldum. Projeyi Murat Yücedağ'ın Youtube kanalında bulunan <i>"50 Derste MVC5 ile Tatil & Seyahat Sitesi"</i> eğitim serisini takip ederek Admin Panel için gelişmiş bir tema kullanmadan, kullanıcı arayüzü için W3Layouts blog temasıyla basit bir kişisel seyahat, gezi blog web sitesi geliştirdim. <a href="https://www.youtube.com/playlist?list=PLKnjBHu2xXNNhJQ6SyF7Wyhqza9mkMGSw" target="_blank"> Buraya</a> tıklayarak eğitim serisine ulaşabilirsiniz.

Proje Başlangıç: 14.04.2025 Pazartesi <br>
Proje Bitiş: 22.05.2025 Çarşamba <br>
Proje Süresi: Haftada 3 gün olarak 19 günde tamamladım.

## 🧰 Kullandığım Teknolojiler ve Kütüphaneler
:heavy_check_mark: ASP.Net MVC5\
:heavy_check_mark: Entity Framework Code First\
:heavy_check_mark: HTML - CSS - Bootstrap\
:heavy_check_mark: JS - AJAX\
:heavy_check_mark: MSSQL Server Veritabanı\
:heavy_check_mark: Admin Paneli Sayfalama, Popup Modal\
:heavy_check_mark: Authentication\
:heavy_check_mark: LINQ
